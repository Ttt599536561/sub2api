## 开发和验证入口

共享流程见 [开发指南](../DEV_GUIDE.md)。本机所有项目命令在同一次 PowerShell 7.3+ 调用中先执行：

```powershell
. 'E:\sub2二次开发项目\tools\project-env.ps1'
```

本机缓存和临时文件在项目 `.cache`，交付产物在 `output`，新工作树在 `.worktrees`。独立终端和已有聊天仍需显式载入脚本；不能假设上一调用的环境会保留。Docker 构建或容器测试前，还须核对实际数据盘位于 E 盘。

后端当前版本以 `backend/go.mod` 为准，当前为 Go `1.27.2`，CI 的版本断言与 Docker 构建镜像一致。前端使用 pnpm；当前 Dockerfile 固定为 `9.15.9`。不要只按本机默认 pnpm shim 的版本重新安装已有依赖。部署 PostgreSQL 主版本和配置沿用现有服务器，测试容器版本不代表生产数据库版本。

本次文档整理核对提交、已有报告、文档链接和文件跟踪状态，不重新执行历史应用测试、不访问生产服务器。过去的本机工作区验证与同源码 GitHub 发布验证分别记录，不能相互替代。
