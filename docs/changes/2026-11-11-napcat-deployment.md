## 用户后续配置

在管理后台`/admin/welfare`的「福利管理 → QQ邀请奖励」完成：

1. 让福利QQ加入目标群，准备好订阅类型分组。
2. 「活动与奖励 → 创建活动」填写名称、群号、起止时间、订阅分组及用户确定的文案并保存。私信模板保留`{code}`和`{url}`；群文案不放兑换码。
3. 「月卡库存」可手动批量「生成30天月卡并入池」，或粘贴同分组的已有未使用30天码，依次预检、入池。每批最多500张，无自动补库存开关。
4. 「活动设置」同步现有成员基线，成功且库存就绪后「启用活动」。
5. 最后在「连接与扫码登录」打开「启用邀请奖励接收」并保存；在资格与发奖记录查看结果。

资格门槛针对被邀请人的QQ等级，必须严格大于10；不限制机器人自身等级。同一被邀请人在整场活动只奖励一次；邀请者邀请不同新人可多次获奖。普通审批事件不能证明真实邀请者，归属不明或等级未知须审核。兑换时同订阅分组延长时长，不同分组增加对应订阅。
