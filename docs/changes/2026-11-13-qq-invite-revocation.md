# QQ邀请退群奖励撤销

日期：2026-11-13（Asia/Shanghai）。源码基于1e08e9007；本记录与本次实现一并提交。GitHub发布与部署状态以HANDOFF和0.2.21-r4发布说明为准。

## 行为

- 保留现有邀请者、被邀请者、活动、原邀请群、码池与奖励的一对一映射。OneBot签名与机器人账号校验后接收group_decrease（主动退出或被踢）；机器人自身被踢不会撤销其他成员。
- 原邀请群退群撤销本次资格；其他群退出不影响原奖励，同活动退群重进不重复发奖。历史已发码有映射者同样适用。重复/乱序回调保持幂等，先退群后收到入群回调不能漏发后再获奖。暂停活动或新奖励接收后，仍处理历史奖励退群及撤销通知。
- 未兑换的码改为cancelled，数据库触发器阻止恢复unused/再次使用；兑换页面显示“兑换码无效，已被取消本次资格。被邀请者已退出群聊。”
- 已兑换保留used、兑换人和原授予凭据，从实际兑换账户的原福利周期扣该码授予的日/周/月额度，月总额度最低0。不扣充值余额、不改变普通付费订阅，不改期限和已使用量，不影响后续新周期。管理员调整过的月额度按当前总额减该码原授予额度，不重新按流水总和覆盖调整。授予次数保留历史累计含义。
- 所有运算使用数据库NUMERIC，撤销递增额度调整版本，避免旧管理员表单覆盖。可选日/周无限额度的卡被撤销后，恢复剩余有效卡的限额。
- 群内提示“{被邀请者QQ}已退出群聊，已取消本次月卡资格”；邀请者私信收到对应码作废或已兑额度收回说明。普通群通知不包含完整码。通知失败使用既有有限重试，结果不确定不会盲目重发；邀请者私信“领取奖励”只重试取消说明，不会恢复原码。
- 后台记录和库存显示退群已取消，撤销群/私信投递分开显示；禁用重查资格及重发原奖励。历史兑换凭据缺失时记录人工核对并明确告知尚未自动扣回，不猜测扣其他权益。
