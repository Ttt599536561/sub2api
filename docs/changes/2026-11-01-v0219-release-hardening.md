1. **Gemini Claude 兼容响应的图片计费（P2）**：`/v1/messages` 转换不输出上游图片，不能按新增 `fileData` / `file_data` 计数收费，也不能由标准图片模型名称回退补一张。保留实际 token 用量并沿用正常模型/渠道定价，不再由被丢弃图片触发按张分支；显式配置的按次定价仍遵循原规则。Gemini 原生接口保留 file/inline 图片计数与完整交付边界；Chat Completions 已交付的 inline 图片行为保持。
2. **余额流水嵌套资源越权（P2）**：受限管理密钥返回显式的流水字段白名单及关联 ID，不嵌套当前用户或分组配置，避免 `users.balance.read` 隐式获得分组配置读取能力。JWT 管理员和旧全权密钥保持原响应；即使受限密钥另外拥有 `users.read` / `groups.read`，也通过独立资源接口读取关联资料。
3. **受限用户搜索匹配隐藏凭证（P1）**：发布前复核确认用户列表虽已脱敏，搜索条件仍可匹配隐藏 API Key 和用户备注。受限身份现在仅匹配邮箱、用户名，计数和列表使用相同查询约束；完整管理员的原搜索能力保持。回归只使用合成凭证及本地内存数据库，没有查询真实用户密钥。

没有新增数据库迁移、资金调整、真实模型调用或账号凭证轮换。此前 `587133d4b` 的支付响应脱敏、PAY- 保留命名空间、零图图片 SSE 和管理密钥刷新竞态修复继续保留，见[上一轮修复记录](2026-11-01-upstream-v0219-review-fixes.md)。
