# QQ 回复文案自由编辑

日期：2026-10-24（Asia/Shanghai）。稳定变更主题：`fix: allow optional QQ reply fields and arbitrary plain text`。用户反馈删除“时间所属时区”报错，实际需要自己决定回复内容，而非只能调整必需占位符位置。整段由管理员决定，时间、分组、规则说明均可删除，可直接写任意非空文字；已有30种自动数据按场景可选插入。用户未理解“新增可复用变量”概念，本轮不增加另一套配置、任意变量源、执行表达式或新机器人指令。实现、独立审查及部署验收已完成，兼容QQ Worker先部署，随后仅更新Sub2测试应用，正式站未改；源码未提交或公开发布。

## 根因与设计

初版Go replyDefinition把所有允许变量设为required_variables，CF validateText再次强制全部恰好一次，前端照此禁保存。本轮取消这项展示限制：26场景的required_variables均为空，可零次或重复使用已有允许变量（仍受最终长度限制），亦可纯文字。此前模板/中文编辑记录中的“必需变量、只能一次”是历史规则，已由此次全可选行为替代。所有授权/群白名单/绑定、价格/资金/订单/去重/图片策略继续由业务代码执行，不以文案出现与否控制。默认文案保留、现有版本/历史不改，不自动替用户删字。

保留未知变量、畸形占位符、非法控制符、超长和空白内容校验，变量展开单遍、长度不截断。仅空动态值展开时不可发空QQ消息：预览返回`empty_rendered_text`并提示补充文字，实际发送按原默认/安全回退处理；不把删除某一信息等同停发整条消息。普通文字可自由增删改，任意新增动态数据源不在本轮范围。

前端保留中文名称/说明和即时预览，改为“自动内容均可选，可全部删除，或直接写自己的文字”。动态字段仍用现有接口规范标记，展示信息不强制保留；保存、审计、冲突和回滚保持。

同时更新独立QQ Worker的只读同步校验；先发布兼容旧/新文案的Worker，再更新Sub2测试站，避免后台保存后CF拒收。正式Sub2站、AI网站/Cron/生成服务不在部署范围，无新迁移、secret或环境变化，不代发QQ群消息或付费请求，不提交、推送或发布公开镜像。图片继续服务器PostgreSQL BYTEA存储，不接R2。
