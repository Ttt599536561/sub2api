# 🎁 签到领福利，消费送抽奖

福利中心提供每日签到、消费抽奖和余额兑换。活动开放期间，可在页面查看参与状态与可用抽奖次数。

## 🎁 消费送抽奖，每次都有奖

活动开放后，API 调用产生的**实际账户余额消费每累计满 $50，即可获得 1 次抽奖机会**。不足 $50 的部分会继续累计。

- 每次抽奖消耗 1 次机会，**不额外扣除账户余额**。
- 每次抽奖均可获得福利余额，单次奖励为 **$0.01～$1**，作为日常使用的小额补贴。
- 奖池包含 **$0.01、$0.02、$0.05、$0.10、$0.20、$0.50、$1** 七档奖励，各档中奖概率可在福利中心查看。
- 每次抽奖独立，没有按累计抽数触发的额外保底。

> API 消费资格仅统计活动开放且未暂停时的实际账户余额扣款。充值、订阅额度内用量不计入，活动开放前的历史消费不补发抽奖次数。

人民币订阅套餐单笔实付每满 **50 元**也可获赠 **1 次**抽奖机会，余数不跨订单累计；仅限活动开放且未暂停时首次完成的合格付费订阅订单。退款成功后按剩余净实付重算赠送次数，已使用的减少权益由后续获得的次数抵扣。具体参与范围可在福利中心查看。

## 📅 每日签到，也有惊喜

活动开放期间，每天进入福利中心签到，即可领取随机小额福利余额。连续签到达到 **7 天、15 天、30 天**，还可获得额外奖励！

签到按**北京时间每日 00:00**划分，每天一次，不支持补签。30 天为一轮；断签会重新计算连续签到进度，累计签到天数保留。

## 💰 福利余额，1:1 兑换使用

签到和抽奖奖励会先存入**福利余额**。点击“兑换余额”，即可按 **1:1** 转入账户余额，用于后续 API 消费。

支持部分或全部兑换，**无手续费**。签到、抽奖和兑换明细均可在“福利记录”中查看。

## 🚀 如何参与

登录后，点击左侧菜单 **「福利中心」**，即可签到、查看抽奖次数并领取奖励。
